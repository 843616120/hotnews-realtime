## 评分维度与技术结论

PDF 评分为功能 35、时间/状态 20、可靠性 15、性能/倾斜 15、工程质量 15 分；**这里不自评得分**。独立 SQL 和 Java 测试支撑规则逻辑，Day 5 样本支撑一次实际恢复，Day 6 隔离实验支撑反压定位。但没有证据可把这些直接合并成“稳定 2000 events/s 的完整链路”或“全系统 Exactly-Once”。规则 C 缺字段、长时间回放的外部版本边界、独立 API/看板和最终监控截图仍应进入已知问题清单。

复验顺序：核对 Kafka 批次与源文件 -> 独立 SQL 与 Java 回归 -> 有界 Flink 日志逐键比较 -> 无并发写入时查询 MySQL/Redis -> 记录实际 Checkpoint/Savepoint 与故障前后快照 -> 汇总资源、吞吐、p95、Lag。最终提交截止是 **2026 年 10 月 6 日**；提交 ID 与版本标签只有真实推送后才能填写，不能用本地状态代替。
